## ◇ &nbsp;El propósito

- **Pasar del vibe coding a la ingeniería asistida.** Usar IA para construir software con criterio, evidencia y control humano.
- **Conceptos abiertos, práctica concreta.** MCP, Agent Skills, `AGENTS.md` y Spec-Driven Development se enseñan como estándares; los laboratorios se hacen con Claude y Claude Code.
- **Material vivo.** Cada unidad se abre según el calendario de clases y queda disponible para repasar después.

## ◇ &nbsp;El hilo conductor

<p align="center"><strong>Pedidos Legado &nbsp;→&nbsp; Pedidos Web</strong></p>

Un solo caso evoluciona durante todo el curso. Cada entregable se apoya en el anterior:

1. Mapa de uso de IA en el SDLC
2. Flujo completo guiado por especificación
3. Módulo funcional desarrollado y documentado con IA
4. Diagnóstico técnico del sistema legado
5. Plan de modernización de la aplicación legada
6. Pipeline con tests automatizados asistidos por IA
7. Proceso completo de code review asistido por IA
8. Guía de gobernanza para el uso de IA
9. Plan de evolución de la IA para una Business Unit
10. **Plan integrado de adopción de IA**

<br>

## ◇ &nbsp;Principios del sitio

- **Hecho para estudiar.** Lectura cómoda, jerarquía clara y navegación simple entre unidades.
- **Dos temas, la misma terminación.** Oscuro por defecto, claro a un clic.
- **Accesible.** Pensado para WCAG 2.2 AA, teclado completo y movimiento reducido.
- **Sin dependencias pesadas.** HTML, CSS y JavaScript nativos, publicado en GitHub Pages.
